# mcp-flow-google — паспорт проекта

> Для агентов Manager. Сгенерировано автоматически 2026-10-19 по коду репозитория, проверь и поправь при необходимости.

**Что это.** Публичный MCP-сервер, через который ИИ-агент (Claude Code, Cursor и др.) генерирует изображения и видео в Google Flow от имени аккаунта самого пользователя. Репозиторий — только документация и гайд по подключению к hosted-сервису openflowmcp.com; кода реализации здесь нет.
**Стек.** Markdown-документация; MCP (Model Context Protocol), транспорт HTTP (remote server); внешние модели Google: Nano Banana 2 / Pro / Lite, видео 4–10 с. Исходников сервиса в репозитории нет.
**Статус.** активен (последние коммиты 2026-08-02, правки документации)
**Где работает.** Хостится как публичный сервис: https://openflowmcp.com/mcp (MCP по HTTP, авторизация Bearer-ключом); сам рантайм вне репозитория

## Запуск локально
- `claude mcp add --transport http openflow https://openflowmcp.com/mcp  # подключение к hosted-серверу, локального запуска из репо нет`

## Осторожно
- Google-аккаунт пользователя: токены хранятся зашифрованными (AES), пароль проходит только на странице Google; не логировать и не пересылать токены/ключи
- Кредиты и квоты Google-аккаунта: видео тратит кредиты (7/10/12 за 4/6/8 с), у Nano Banana Pro отдельная суточная квота
- Платная подписка $2/мес на видео — биллинг, менять осторожно
- Файлы результатов лежат на сервере до заполнения диска; удаляются только уже скачанные — не удалять чужие/несохранённые результаты
- Лимит 8 одновременных генераций на аккаунт: превышение ставит задачу в очередь, а не даёт ошибку
